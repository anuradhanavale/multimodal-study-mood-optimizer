# Multimodal AI Study Mood Optimizer

An AI-powered study assistant built with **Python and Streamlit** that helps students understand their study readiness and receive personalized study recommendations using multimodal AI.

## Features

-  **Text Analysis** : Analyze user-provided study check-ins.
-  **Audio Analysis** : Process voice input using speech recognition.
-  **Study Notes Analysis** : Upload study notes for content extraction.
-  **AI-Powered Recommendations** : Generate personalized study suggestions.
-  **Progress Tracking** : Visualize study activity and progress.
-  **Adaptive Study Planning** : Recommend study strategies based on user inputs.

## Tech Stack

- **Language:** Python
- **Frontend:** Streamlit
- **AI/ML:** Machine Learning, NLP, Multimodal AI
- **Data Processing:** Pandas, NumPy
- **Visualization:** Plotly
